# Phishing Awareness Simulation & GoPhish Telemetry Lab

A Python phishing awareness and campaign analytics lab built on Kali Linux for an Internee.pk cybersecurity internship task.

## Modules & Artifacts
- `templates/gophish_campaign_config.json`: GoPhish-style phishing simulation templates and red-flag indicators.
- `gophish_phishing_sim.py`: Simulates authorized training interactions (`opened`, `clicked`, `submitted`, `reported`).
- `phishing_awareness_report.py`: Calculates click/report metrics and generates `AWARENESS_REPORT.md` and `submission_summary.txt`.
- `index.html`: Interactive awareness telemetry dashboard for GitHub Pages live deployment.
